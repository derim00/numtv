NUM TV : installateur pour NumWorks n0120 (PC Windows)
==========================================================

Rien à installer : ni Python, ni pilote. Windows reconnaît la calculatrice
tout seul.

1. Décompresse le zip (clic droit > Extraire tout). Ne lance pas
   l'installateur depuis l'intérieur du zip.

2. Double-clic sur « Installer NUM TV.exe ».
   Si Windows affiche « Windows a protégé votre ordinateur » :
   Informations complémentaires > Exécuter quand même.
   Une fenêtre noire s'ouvre, puis la page de l'installateur dans ton
   navigateur. Laisse la fenêtre noire ouverte ; ferme-la à la fin pour
   quitter.

3. Branche la calculatrice en USB et appuie sur Reset au dos :
   elle redémarre sur le système officiel (slot A).

4. Quand le voyant passe au vert, clique sur « Installer NUM TV ».
   Ne débranche pas la calculatrice pendant l'installation.

Les jeux déjà dans le dossier games sont prêts à installer. Pour ajouter
d'autres jeux .nwa depuis Windows, installe aussi la chaîne ARM
(Arm GNU Toolchain, « arm-none-eabi », sur developer.arm.com), ou ajoute-les
dans le dossier games/ de ta copie privée sur GitHub et relance la
compilation.

Si la page dit que la calculatrice est introuvable alors qu'elle est
branchée : ferme les autres programmes qui l'utilisent (site de NumWorks,
NumSocial, un autre installateur), essaie un autre câble ou un autre port USB,
puis rappuie sur Reset.

NUM TV s'installe dans le slot B : le système officiel (slot A) n'est
jamais modifié. Après un Reset, la calculatrice revient sur le système
officiel ; il suffit de relancer l'installation pour retrouver NUM TV.

Les commandes de NUM TV
-----------------------

Haut / Bas ............. zapper (chaîne suivante / précédente)
0 à 9 .................. taper un numéro de chaîne (1 à 9 : les émissions,
                         10 et plus : les applis et les jeux)
0 ...................... la chaîne précédente
+ / - .................. le volume (la télé est muette : c'est la luminosité)
OK ..................... regarder (ouvre l'appli) / agir dans l'émission
Retour ................. le programme télé
Boîte à outils ......... le télétexte (touches, chaînes, audimat, réglages)
Ans .................... zapping au hasard
x,n,t .................. taper sur la télé (quand l'image déraille)
Effacer ................ BOUTON PANIQUE : Calculs s'ouvre tout de suite

Les chaînes
-----------

1 LE JT ............. tes calculs deviennent des infos (essaie 6×7, 0/0, 1+1)
2 MÉTÉO DU LYCÉE .... < > : le jour de la semaine
3 TÉLÉ-ACHAT ........ < > : les produits, OK : commander
4 LA ROUE ........... < > : nombre d'élèves (ou la roue des gages), OK
5 DÉTECTOR 3000 ..... garde OK appuyé. Secret : < avant = VÉRITÉ,
                      > avant = MENSONGE (le point du sous-titre change)
6 EXCUSOMATIC ....... OK : tirer le levier
7 LE GRAND QUIZ ..... jokers : 1 (50/50), 2 (public), 3 (ami)
8 FEU DE CHEMINÉE ... < > : bois, copies de maths, chimie, disco
9 ÉCRAN DE VEILLE ... le logo rebondit. Un jour, il touchera le coin.
